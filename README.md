# inkspire-dictionaries

Скачиваемые словари для читалки Inkspire («слово из книги → английские значения» + таблица форм слов).
Файлы собираются автоматически из открытых данных и лежат в разделе **Releases** этого репозитория.

## Как собрать словари
Сборка запускается **сама** при каждой отправке в `main`, а вручную — вкладка **Actions** → «Собрать словари» →
**Run workflow**. Для каждого языка (fr, es, de, it, pt, ja, zh) собираются две пары: «язык → English»
(английское издание Викисловаря) и «язык → русский» (русское издание). Через 10–20 минут в **Releases**
появится релиз `dictionaries-<номер>`:
- `fr-en.dict.gz`, `fr-ru.dict.gz` — словари (слово → значения);
- `fr-en-forms.dict.gz`, `fr-ru-forms.dict.gz` — формы слов (`mangeait` → `manger`);
- `catalog.json` — список для приложения (пара, размер, контрольная сумма);
- `SHA256SUMS.txt` — контрольные суммы для проверки.

## Что внутри
- `src/` — сборщик (чистая Java, без зависимостей кроме Gson): читает выгрузку английского Викисловаря
  (kaikki.org), оставляет слово, часть речи, до 4 коротких значений и формы слов.
- `.github/workflows/build-pack.yml` — сборка и публикация релиза.
- `CREDITS.md` — источники, авторы и лицензии.
